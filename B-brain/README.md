## 🎯 How Agents Use This Directory

### Copywriter
1. Always check `ran-voice-examples/` before writing
2. Reference `target-personas.md` for audience calibration
3. Check `content-calendar.md` for topic context and sequence

### Researcher (Scout)
1. Save research briefs to `research/`
2. Update `content-calendar.md` with discovered topics and angles
3. Flag emerging trends for Strategist review

### Strategist
1. Maintain `content-calendar.md` — quarterly and weekly view
2. Use `target-personas.md` for ICP alignment
3. Review and update `target-personas.md` as ICP sharpens

### Gatekeeper
1. Reference `ran-voice-examples/` for voice validation
2. Flag any drift from Ran's established voice patterns

## Ran's Voice (Quick Reference)

- **Executive** — Peer-to-peer, not teacher-to-student
- **Contrarian** — Challenges consensus, offers the non-obvious take
- **Crisp** — Short sentences. No padding. Gets to the point.
- **Specific** — Numbers, timeframes, concrete examples over vague claims
- **Direct** — Says what he thinks. No hedging.

**Always read `C-core/voice-dna.md` for the full voice profile.**

## Content Calendar Convention

Content is planned by week (W01, W02...) with:
- Topic / angle
- Content type (LinkedIn post, article, carousel)
- Status (planned / in-progress / done)
- Output location
